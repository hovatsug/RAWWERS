# RAWWERS brand assets

Everything here is generated by `make brand` (see `tools/brand/`) from the
colour tokens in `app/lib/design/tokens.dart` and the app's Archivo font.
Don't edit these files by hand: change a token or a proportion in
`tools/brand/generate.mjs` and regenerate.

## Files

| File | What it is |
|---|---|
| `logo-primary-on-dark.svg` | RAWWERS in four corners: corners Meter 500, word Ink 050. On Ink 950 and on photos under the dark band. |
| `logo-primary-on-light.svg` | Corners Meter 700, word Ink 950. On paper and white. |
| `logo-mono-ink.svg`, `logo-mono-white.svg` | One colour: under 120px wide, stamps, e-mail, print. |
| `icon-client.svg`, `icon-pro.svg` | 1024 app icon masters: the R in four corners. Client dark, pro inverted on paper. |
| `icon-foreground-*.svg`, `icon-background-*.svg` | Android adaptive layers. The foreground's artwork sits inside the 66dp safe circle. |
| `icon-monochrome.svg` | Android themed icon (the launcher recolours it). |
| `exports/logo-primary-on-light@2x.png` | For e-mail templates. |

The four logo files are also copied to `app/assets/brand/` (drawn by
`RLogo`, sized from the generated `app/lib/design/brand.dart`) and
`web/public/brand/` (the admin's login and sidebar).

## Colours (tokens)

| Use | Token | Hex |
|---|---|---|
| Dark ground, dark text | `RInk.i950` | `#0E0F11` |
| Light text on dark | `RInk.i050` | `#FAFAFA` |
| Corners on dark | `RAccent.meter500` | `#4A7FA5` |
| Corners on light | `RAccent.meter700` | `#2C4F66` |
| Pro icon ground | `RPaper.paper` | `#F2F2F0` |

One accent only. A test (`app/test/brand/`) fails if any file here uses a
colour outside this set.

## Geometry

- Word: Archivo 700, letter-spacing 0.16em, converted to outlines.
- Corners, at a 32px cap height: 2px stroke, 14px arms, 24px (sides) and
  20px (top, bottom) from the word. The same proportions at every size.
- Clear space: the height of the R on every side, kept free of other text
  and edges.
- Minimum size: the two-colour logo 120px wide; below that, the mono one
  (`LOGO_MIN_PRIMARY_WIDTH` in the generator; `RLogo` switches on its own).
  The icon mark at any size the platforms ask for.

## Don't

- Recolour, outline, or add a second accent.
- Stretch, skew or rotate.
- Add gradients, shadows, glows or 3D.
- Put the logo on a busy photo without the dark band behind it.
- Add the exposure bar: it belongs to the app (`RExposureScale`), not the
  logo.
